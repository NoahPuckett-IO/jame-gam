# Tiny Henry

A tiny adventure in a very big store.

Henry was out for a walk in the woods when a flying saucer showed up. One tractor beam and one zap of a shrink ray later, he wakes up inside a cereal box in the middle of an enormous grocery store, now about the size of a can of beans.

Getting out means crossing the whole store:

- **Aisle 1:** lever a fallen cereal box out of the way with a ruler, stack a box to climb a ledge, and build a ramp from a cutting board and a spatula.
- **Aisle 2:** the floor is glued with spilled soda, so climb the shelves, balance on a mop handle, bounce off a sponge and ride a swinging paper plate.
- **Aisle 3:** a frozen aisle of glass-door freezers, melt water, bouncing whipped cream and ice that cracks under you.
- **Aisle 4:** groceries rain off the shelves. Red dashed outlines show where each one will land.
- **Aisle 5:** someone left the robot vacuum on. Hide from its scanner, survive its rampage, then jump on its power button.

## Play

Download the latest Windows build from the game's itch.io page, extract the zip and run `Tiny Henry.exe`. If Windows shows "Windows protected your PC", click **More info → Run anyway**.

## Controls

| Action | Key |
|---|---|
| Move | W A S D |
| Look | Mouse |
| Jump | Space |
| Dash (recharges in five seconds) | Shift |
| Pick up / put down | E |
| Pause | Esc |

Every key can be rebound in **Settings**, which also has master, music and sound-effect volume and mouse sensitivity.

## Building from source

The project uses **Unity 6000.6.7f1** with the Universal Render Pipeline. Large files (models, textures, audio, the scene) are stored with Git LFS, so install it before cloning:

```bash
git lfs install
git clone https://github.com/NoahPuckett-IO/jame-gam.git
```

Open the folder in Unity Hub, then open `Assets/JameGamGame.unity`.

The whole store, every level, the intro and the menus are generated by editor scripts in `Assets/Editor`:

- **JameGam → Build Grocery Store** (Ctrl+Shift+Alt+B) rebuilds the scene.
- **JameGam → Build Windows Game** (Ctrl+Shift+Alt+W) builds the game to `Desktop/TinyHenryBuild`.

Gameplay scripts live in `Assets/Scripts`.
